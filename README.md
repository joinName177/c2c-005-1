# c2c-005 · 声音表情包工坊

Vue 3 + TypeScript + Vite 纯前端声音创作工具。录音或导入的素材进入素材池（原素材始终保留），在多片段编排台分别选择保留范围、按时间线排序、插入静音与相邻交叉淡化，总时长扣除重叠不超过 10 秒；试听与最终保存使用同一份离线合成结果，再进行声学特征情绪匹配、Canvas 封面制作，最后存入 IndexedDB 本地作品集或分享。

## 多片段编排台

- 素材池可放多段录音或导入文件；片段只记录“保留范围 + 之后静音 + 与下一段交叉淡化”的选择，不改动原素材。
- 时间线按顺序排列，修改前一段长度后后续位置自动重排；总时长 = Σ片段 + Σ静音 − Σ交叉淡化重叠，实时计算并显示，超过 10 秒禁止合成。
- “生成试听”与最终保存共用 `AudioArrangerPort` 的同一份合成产物（WAV），不会出现听到的和存下的不一致。
- 合成或情绪分析进行中继续编辑，刚完成的旧结果立即标记失效，需重新生成；合成/分析失败时编排完整保留，可原样重试。
- 删除仍被片段引用的素材时，先弹窗列出受影响片段，用户可取消或一并移除这些片段。
- 未完成的编排（含素材 Blob）自动保存在 IndexedDB，重新打开可一键接着编辑；已保存作品再次编辑时恢复完整编排。素材缺失的旧作品回退为单段音频编辑。

## 架构

- `src/core`：作品模型、编排时间线纯函数（`arrangement.ts`）、特征归一化、情绪规则与封面预设
- `src/ports`：录音、音频分析/裁剪/编排合成、Canvas、作品与草稿仓储、分享接口
- `src/adapters`：MediaRecorder、Web Audio（解码/重采样/WAV 混音）、Canvas、IndexedDB、Web Share 实现
- `src/ui`：Vue 阶段式工作流（录音 → 编排 → 情绪 → 封面 → 作品集）和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

本地开发默认由 Vite 提供；Docker 部署访问 `http://localhost:8105`。浏览器录音在非 localhost 环境通常需要 HTTPS 和麦克风权限。

声音只保存在本机 IndexedDB，不会上传。生成的分享链接仅承载标题、情绪和封面配置，不包含原始音频；文件分享不受此限制。情绪识别是娱乐性启发式结果，不代表身份、性格或医学判断。
