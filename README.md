# c2c-005 · 声音表情包工坊

Vue 3 + TypeScript + Vite 纯前端声音创作工具。支持最长 10 秒录音/导入、多片段编排（素材池、保留范围、静音插入、相邻交叉淡化）、声学特征情绪匹配、Canvas 封面、IndexedDB 本地作品集和系统文件分享。

## 编排工作流

1. **录音/导入**：素材进入素材池，原始音频始终保留，剪辑只记录保留范围等选择。
2. **编排台**：把素材按时间线排序，可插入静音、为相邻片段设置交叉淡化；扣除重叠后的总时长不得超过 10 秒，调整任一片段长度后后续位置自动重排。试听与最终保存使用同一份编排。
3. **合成与情绪分析**：两者都完成后才能确认作品；处理中继续编辑会使旧结果失效，失败会保留编排供重试。素材与编排草稿持久化在 IndexedDB，重新打开可接着编辑；删除仍被引用的素材会先列出受影响片段，可取消或一并移除。

## 架构

- `src/core`：作品模型、特征归一化、情绪规则与封面预设
- `src/ports`：录音、音频、Canvas、仓储与分享接口
- `src/adapters`：MediaRecorder、Web Audio、Canvas、IndexedDB、Web Share 实现
- `src/ui`：Vue 阶段式工作流和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

本地开发默认由 Vite 提供；Docker 部署访问 `http://localhost:8105`。浏览器录音在非 localhost 环境通常需要 HTTPS 和麦克风权限。

声音只保存在本机 IndexedDB，不会上传。生成的分享链接仅承载标题、情绪和封面配置，不包含原始音频；文件分享不受此限制。情绪识别是娱乐性启发式结果，不代表身份、性格或医学判断。
